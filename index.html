연구원별 제각각인 세포배양 데이터를 완전한 DB로 통일하세요

연구원마다 다른 컬럼명, 단위(10^5 vs 10^6 cells/mL, mM vs g/L), 일시 표현(Day 0, 48h), 세포주 표기(cho k1 vs CHO-K1), 결측치(< LOD, N/A)를 자동으로 정제·검증하여 표준 Long/Wide DB로 구축합니다.

기본 파싱 설정

식별자 컬럼 매핑 (Identifier Columns)

실험 ID, 배양일, 날짜, 세포주, 배양용기 등 기본 식별 정보를 매핑하세요.

측정 파라미터 컬럼 (Measurement Columns) 0개 선택됨

Long format으로 Unpivot할 측정값 컬럼들과 단위를 지정하세요.

⚡

데이터 유효성 검증 & 전처리 규칙 (Rules Engine)

이상치/단위/결측치/텍스트 오류를 브라우저에서 자동 정제합니다.

음수 & 이상치(Outlier) 처리

파라미터별 정상 범위(Viability 0~100%, VCD 음수 방지 등) 초과 시 경고 또는 제외

단위 자동 표준화 (Unit Normalization)

10^5 cells/mL ➔ 10^6, mM ➔ g/L 분자량 자동 환산

Glucose(MW 180.16), Lactate(MW 90.08)
실험 조건 텍스트 정규화

세포주(cho k1 ➔ CHO-K1), 용기(shake flask ➔ Shake Flask) 통일

공백 Trim, 특수문자 정제, 별칭 사전 자동 매핑
결측치(Missing Values) 처리 전략 < LOD / N/A 구분
